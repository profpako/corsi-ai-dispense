Riceve un obiettivo

Costruire il wiki

COPIA QUESTO PROMPT Realizza una piccola app web locale per archiviare le mie lezioni. Importa in blocco i tre file 09–11 del kit e permetti altri import multipli di MD, DOCX e PDF. Per ogni scheda mostra titolo, disciplina, classe, durata, obiettivi, materiali, svolgimento, verifica e nome del file di origine. Lascia vuoti i campi assenti. Aggiungi ricerca nel testo, filtri per disciplina e classe, modifica manuale, salvataggio locale ed esportazione di un backup JSON. Prima di salvare un’importazione mostra l’anteprima; se reimporto lo stesso nome file, aggiorna la scheda esistente. Includi istruzioni di avvio e una prova: cercando “temperatura” trovo Scienze, e importando due volte 09_lezione_storia.md ottengo una sola scheda.

Per la demo importa prima i tre file Markdown. L’importazione DOCX/PDF è il test successivo, perché la struttura può variare.

Progressione didattica · 1

Prima: l’AI genera uno script Apps Script

È il modo più semplice per far capire che un’AI può aiutare a creare un’automazione concreta, senza costruire subito un’app completa.

PROMPT A UN’AI Scrivi uno script Google Apps Script che crea un Google Modulo chiamato “Ripasso di biologia” con 3 domande a scelta multipla e una domanda aperta. Usa FormApp. Aggiungi commenti in italiano e una funzione createQuiz().

In laboratorio

  1. Apri script.google.com.
  2. Incolla e leggi lo script.
  3. Autorizza con consapevolezza.
  4. Esegui, apri il modulo, modifica una domanda.

Obiettivo: capire il ciclo “richiesta → codice → azione → controllo”.

Fase 1 · una base leggibile

Lo script: breve, commentato, verificabile

function createQuiz() {
  // Crea un modulo e conserva il link di modifica nel registro.
  const form = FormApp.create('Ripasso di biologia');
  form.setDescription('Controlla le risposte prima di assegnarlo.');
  form.addMultipleChoiceItem()
      .setTitle('Qual è l’unità fondamentale della vita?')
      .setChoiceValues(['La cellula', 'Il tessuto', 'L’organo']);
  form.addParagraphTextItem().setTitle('Spiega la tua scelta.');
  Logger.log(form.getEditUrl());
}

Nota: gli elementi esatti e le opzioni quiz possono evolvere. Prima della demo, esegui sempre un test nel tuo account Google.

Progressione didattica · 2

Poi: lo script legge dati strutturati

Invece di domande scritte nel codice

Lo script riceve un elenco organizzato. Così le domande possono venire da una chat, da un foglio oppure da una chiamata AI.

{
  "title": "Ripasso di biologia",
  "questions": [
    {"type":"choice", "text":"...",
     "options":["A","B","C"]},
    {"type":"open", "text":"Spiega..."}
  ]
}

Il vantaggio del JSON

  • l’app sa dove trovare ogni campo
  • l’anteprima è facile da creare
  • il docente può cambiare una domanda
  • la creazione del Form è ripetibile

Passaggio chiave: l’AI non “scrive nel modulo”; produce una proposta di dati.

Fase 2 · vincoli chiari

Un prompt che produce un output utilizzabile

RUOLO Sei un progettista di verifiche. Usa esclusivamente le informazioni del testo fornito. COMPITO Genera 5 domande per una classe [LIVELLO], allineate a questi obiettivi: [OBIETTIVI]. Due a scelta multipla, due risposta breve, una aperta. Evita informazioni non presenti. FORMATO OBBLIGATORIO Restituisci SOLO JSON valido: title, description, questions[]. Ogni domanda ha type, text, options (solo per choice), correctAnswer (se dichiarabile), rationale. CONTROLLO Se il testo non basta, inserisci "needsReview": true e spiega il motivo.

Perché funziona?

Ruolo, vincoli, formato e gestione dell’incertezza rendono l’output meno ambiguo.

Test in aula

Confrontate il risultato dello stesso prompt senza il vincolo “solo JSON”. Quale dei due si lascia trasformare più facilmente in un modulo?

Lessico comune

Chat, flusso, agente

💬

Chat

Risponde a una richiesta. Il risultato è testo o un contenuto da usare manualmente.

🔁

Flusso

Esegue passaggi definiti, per esempio caricare un file, estrarre testo e creare una tabella.

🧩

Agente

Riceve un obiettivo, usa strumenti e si ferma quando deve chiedere una conferma.

Doc2Forms è un buon esempio perché rende visibili tutti e tre i livelli.

Prima di automatizzare

Confini del progetto

Fermare l’agente quando

  • deve pubblicare o inviare qualcosa
  • non ha abbastanza informazioni nel materiale
  • trova dati personali o elaborati degli studenti
  • deve scegliere criteri di valutazione

Rendere il flusso affidabile

  • usare un’anteprima modificabile
  • mostrare le fonti del contenuto
  • registrare le incertezze
  • richiedere un clic di conferma per azioni esterne

Nelle esercitazioni usa soltanto i materiali fittizi del kit.

Definizione di completato

Quando Doc2Forms funziona davvero

Prima della creazione del Form

  • mostra il testo estratto
  • restituisce JSON valido
  • segnala i campi incerti
  • permette di modificare o eliminare domande

Al momento della creazione

  • richiede conferma esplicita
  • crea il modulo nell’account corretto
  • restituisce il link di modifica
  • non pubblica o condivide automaticamente

Laboratorio · 10 minuti

Confronto tra le bozze

Chi presenta

Mostra una domanda ben riuscita e una domanda da correggere. Spiega quale modifica hai fatto e perché.

Chi ascolta

Controlla che ogni domanda usi il materiale fornito, misuri un obiettivo e abbia un linguaggio accessibile.

Materiale del kit: confronta sempre la bozza con 01_materiale_storia.docx, non con informazioni trovate altrove.
